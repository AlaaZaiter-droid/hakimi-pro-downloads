# Hakimi Pro - official Windows downloads

Compiled Windows demo installers and release information for Hakimi Pro by Leamaco Tech. The application source code is private and is not published in this repository.

- Arabic product page and demo limits: https://leamacotech.com/hakimi-pro/
- English product page: https://leamacotech.com/hakimi-pro/en/
- Website download link: https://leamacotech.com/downloads/HakimiPro-Demo-Setup-0.11.0.exe

The demo allows 100 medical visits in total across a clinic and 5 new bookings per day, with additional creation limits described on the product page. Full activation retains the same clinic data.

The current evaluation installer uses development self-signing. Windows may display a publisher warning. No private signing keys, license issuer, clinic records or user Google credentials are distributed here.
